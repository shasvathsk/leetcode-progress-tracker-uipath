# LeetCode Progress Tracker Automation

## 📌 Overview
Manually recording LeetCode progress into Excel was repetitive and frustrating.  
This UiPath robot automates the process by scraping profile data, updating Excel, and generating a pivot table for instant insights.

## ⚙️ Features
- Scrapes solved problems count and details from LeetCode profile
- Writes data into Excel automatically
- Generates pivot table for quick visualization

## 🛠️ Tech Stack
- UiPath Studio
- Activities used: Table Extractor, Write Data Table
- Excel Automation

## 🚀 Impact
- Eliminated manual tracking
- Improved efficiency
- Enabled instant performance visualization
